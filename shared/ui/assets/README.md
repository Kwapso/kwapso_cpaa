# assets

The brand's own files. Masters are exactly as the client sent them and are
never edited here; everything derived from a master is generated by
`build-assets.mjs` and says so.

    node assets/build-assets.mjs            # write the derivatives
    node assets/build-assets.mjs --check    # fail if any is stale

- `logos/` — **six vector masters** (`Isotype-*.svg`, `Logotype-*.svg`,
  `Logotype-no-isotype-*.svg`, arrived 2026-08-24) and the PNG masters that
  preceded them. The masters carry canvas padding — the isotype's ink is 55.5%
  of its box — so the build writes trimmed copies as `*-ink.svg`, and those are
  what `components/primitives/brand/brand.tsx` loads. Nothing else in the
  repository may load a logo file directly.
- `app-icons/` — the two field masters, plus a full derived set per door in
  `system/` and `portal/`: `favicon.svg`, `favicon.ico` (a real ICO),
  `apple-touch-icon.png` (no alpha), `icon-192`, `icon-512`, `maskable-512`.
- `photography/` — `exterior-mockup.png`, the picture on every outside screen,
  and three JPEGs derived from it. See that folder's README for the crop.
- `fonts/` — Saans and SerrifCondensed, with `.woff2` generated beside the
  OTF/TTF. The redistribution licence is the one open question; see
  `UPLOAD.md` §6.
- `icons/` — 30 real kwapso glyphs from the kit export, under KIT names
  (`account.svg`). Not the same set as the repository's `icons/` at the root,
  which holds the 96 export names and is still placeholder art.
- `icons-open/` — the 7 outline variants.
- `folder/` — the 9-slice folder-shape corner/tab pieces (chapter 14).

`UPLOAD.md` is the live list of what the client still owes and what breaks
without it. Re-read it against this folder before telling anyone something is
missing — four of its eight sections closed on 2026-08-24 alone.
